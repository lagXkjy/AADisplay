# Android Studio compatibility patch

This patch changes build tooling only:

- Android Gradle Plugin: 9.3.1 -> 8.11.2
- Gradle wrapper: 9.5.1 -> 8.13
- Kotlin plugin remains 2.2.10
- compileSdk / targetSdk remain 36
- No VirtualDisplay, resolution, DPI, viewport, split ratio, touch, phone-input-bridge, or safe-exit runtime logic is changed.
