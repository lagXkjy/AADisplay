# Security / safety

This project hooks Android framework and Android Auto processes. Bugs can cause projection failure, application crashes, `system_server` restarts, or device instability.

For reproducible crash reports, include:

- Android version / OEM skin
- Android Auto version
- LSPosed / root solution version
- exact project commit/tag
- relevant `adb logcat` / DropBox excerpts

Remove personal information from logs before publishing them.

Do not test interactive changes while driving.

For privacy guidance when sharing logs, also see `PRIVACY.md`.
